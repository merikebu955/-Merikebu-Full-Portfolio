SETUP
1. Extract this ZIP into C:\xampp\htdocs\ (replace the existing project files when prompted).
2. Start Apache and MySQL in XAMPP.
3. Open phpMyAdmin and select the merikebu_portfolio database.
4. If you have not already installed the blog tables, import database_upgrade.sql.
   This creates the blog_posts table and inserts example starter articles only when
   their slugs do not already exist.
5. Check config/config.php and ensure BASE_URL and database credentials match your folder.
6. Visit:
   http://localhost/Merikebu_Full_Portfolio/blog.php

ADD OR EDIT ARTICLES
- Sign in to the portfolio admin panel.
- Open the Blog_posts tab.
- Add or edit the title, unique slug, excerpt, content, category, cover image, and
  published status.
- Publish the article to make it visible on the public Blog page.
